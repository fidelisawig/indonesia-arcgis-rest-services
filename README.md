# Cara Mengakses ArcGIS REST Service di QGIS

1. Buka **QGIS** dan tampilkan panel **Browser** (`View → Panels → Browser`).
2. Pada panel **Browser**, klik kanan **ArcGIS REST Servers** → **New Connection...**.
3. Masukkan **Name** (bebas) dan salin **REST Endpoint** dari daftar pada repositori ini ke kolom **URL**.
4. Klik **OK**, lalu klik dua kali koneksi yang telah dibuat.
5. Pilih folder atau layer yang ingin digunakan.
6. Klik kanan layer → **Add Layer to Project**.
7. Untuk layanan yang tidak dapat dibuka, coba akses URL melalui browser untuk memastikan server sedang aktif.
8. Beberapa layanan mungkin memerlukan autentikasi atau memiliki pembatasan akses dari penyedia layanan.
